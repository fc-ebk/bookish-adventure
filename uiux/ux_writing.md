# UX Writing 개선

## 1. 모임 설명 텍스트박스 Placeholder

모임의 대문 및 설명에 해당하는 부분 텍스트박스 placeholder를 조금 더 가이드 있는 방식으로 제안해보려고 해. 지금은 '모임 목표를 설명해주세요.' 라고 되어 있음.

조건 반영:

* 2줄 이내
* 따뜻하고 친절한 톤
* 설명 과다 금지
* 예시(ex) 사용 가능
* 목적·활동·정기성 정보 유도

---

- **안 1: 가장 기본형 (정보 범위 균형)**

```
이 모임은 어떤 모임인가요?
목적, 주요 활동, 정기 모임이 있다면 함께 적어주세요.
```

---

- 안 3: 예시 포함 (구체 유도)

```
모임의 목적과 어떤 활동을 하는지 알려주세요.
ex) 매주 러닝, 월 1회 정기 모임
```

---

- 안 6: 신규 가입자 시점 강조

```
가입을 고민하는 사람에게 도움이 되도록
모임의 목적과 주요 활동을 적어주세요.
```
